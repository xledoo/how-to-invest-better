# 4. 费用与税

投资里最容易被忽略的对手不是市场，而是费用和税。它们平时看起来很小，时间一长却会悄悄吃掉不少到手收益。本章的五个错误，都是在为看不见的成本买单。

### 1. 只看收益不看费率，买高费率产品
<!-- 成本标签: 钱=多 时间=少 毅力=否 收益=大 口径=代价 -->
- 成本：费率高的产品每年都要多扣一笔钱，长期下来这笔钱会越滚越大，直接拉低到手收益。
- 说人话：收益还没到手，费率已经先拿走了自己那份。
- 收益：选费率更低的同类产品后，省下的费用长期留在自己手里。
- 证据等级：A
- 来源：Vanguard 研究，关于费用对长期投资回报影响的投资者教育，https://investor.vanguard.com/investor-resources-education
- 备注：费率低不等于产品一定更好，还要看产品类型、风险和是否适合自己，不能只比费率。改掉做法是：买之前先看费率说明，同类产品之间优先比较费率，再结合风险和目标做选择。

### 2. 忽略交易佣金、印花税、申购赎回费这些小钱
<!-- 成本标签: 钱=少 时间=少 毅力=否 收益=中 口径=代价 -->
- 成本：单次费用看起来很少，但买卖次数一多，加起来就是一笔不小的支出，还容易让人忽略真实成本。
- 说人话：小钱不记账，月底一看全是账。
- 收益：把各项费用算进成本后，买卖决策更清醒，不会被虚高的账面收益误导。
- 证据等级：B
- 来源：SEC 投资者教育，关于投资费用的介绍，https://www.investor.gov/
- 备注：不同市场、不同渠道的费用项目和标准并不相同，要以自己实际使用的渠道公布的费率为准。改掉做法是：交易前先查清佣金、印花税、申购赎回费等全部费用，把它们算进这笔交易的成本里。

### 3. 频繁交易，手续费吃掉收益
<!-- 成本标签: 钱=多 时间=多 毅力=是 收益=大 口径=代价 -->
- 成本：买卖越频繁，手续费、税费和买卖价差的累计支出越高，还要花大量时间盯盘和决策。
- 说人话：交易越勤，中间商赚得越多，你剩得越少。
- 收益：降低交易频率后，费用支出下降，时间省下来，心态也更稳。
- 证据等级：B
- 来源：Barber 与 Odean 关于个人投资者频繁交易的研究，属学术共识；SEC 投资者教育亦有相关提醒，https://www.investor.gov/
- 备注：该研究针对的是特定市场和时期的个人投资者数据，结论是趋势性的，不能直接套用到每个人的每一笔交易。改掉做法是：事先定好买卖规则，减少凭感觉的临时交易，非必要不频繁进出。

### 4. 忽视复利下费率的长期侵蚀，小费率、长时间
<!-- 成本标签: 钱=多 时间=少 毅力=否 收益=大 口径=代价 -->
- 成本：每年多扣的一点费率，会在几十年里不断累积，本应复利增长的那部分钱也被一起扣掉了。
- 说人话：费率像慢漏水，一天看不出，几年差距就出来了。
- 收益：尽早把费率降下来，省下的钱有更长时间留在账户里复利增长。
- 证据等级：A
- 来源：Vanguard 研究，关于费用在长期复利中累积影响的投资者教育，https://investor.vanguard.com/investor-resources-education
- 备注：这是费用按年累积的数学常识，不是收益预测；实际差距取决于费率差、持有时间和市场表现。改掉做法是：把投资期限拉长来看费率，优先选择费率更低的同类产品，并定期检查持仓的费率是否合理。

### 5. 不了解分红税、资本利得税，到手收益打折
<!-- 成本标签: 钱=多 时间=少 毅力=否 收益=中 口径=代价 -->
- 成本：分红和卖出获利可能要缴税，税后到手收益比账面收益少，事先没算税就容易高估回报。
- 说人话：账面赚的不是到手的，税后才是真的。
- 收益：提前了解税的规则后，能更真实地评估收益，避免年底被税单打个措手不及。
- 证据等级：B
- 来源：SEC 投资者教育，关于投资与税务的基础介绍，https://www.investor.gov/
- 备注：税法因国家、地区和个人情况而异，且会变化，本书不提供税务建议，具体问题请以当地现行税法或专业人士意见为准。改掉做法是：在投资前了解自己所在地区对分红、资本利得的征税方式，把税后收益作为评估标准，而不是只看账面收益。
