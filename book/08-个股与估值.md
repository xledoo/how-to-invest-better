# 8. 个股与估值

买个股不是买股价数字，也不是买一个好产品，而是买一家公司的未来赚钱能力。本章列出五个新手在看个股和估值时最容易犯的错误，帮你先看懂业务和财报，再谈价格贵不贵。

### 1. 只看股价便宜就买（低价≠便宜）
<!-- 成本标签: 钱=多 时间=少 毅力=否 收益=大 口径=代价 -->
- 成本：股价低可能只是因为公司变差了，买入后股价还可能继续跌，钱会被套在基本面走弱的公司里。
- 说人话：股价低不等于便宜，便宜要看公司值不值这个价。
- 收益：少踩“越跌越买、越买越跌”的坑，买入前先问一句为什么便宜。
- 证据等级：C
- 来源：无直接对照研究，属投资者教育共识
- 备注：本条是估值常识层面的提醒，没有直接对照研究可以量化“低价股必然亏钱”，便宜与否要结合盈利、资产和前景一起看。改掉做法是：看到低价先查公司近几年盈利和负债有没有明显恶化，再用估值和同行比较判断，而不是只看股价数字。

### 2. 只看市盈率一个指标就下判断
<!-- 成本标签: 钱=多 时间=少 毅力=否 收益=中 口径=代价 -->
- 成本：只看市盈率容易误判，市盈率低可能是盈利不可持续，市盈率高也可能对应更快的成长，单看一个数就买卖容易买错。
- 说人话：市盈率只是一张快照，看不懂背后的盈利质量，光看它会看走眼。
- 收益：判断更全面，不容易被一个“看起来很低”或“看起来很高”的数字带偏。
- 证据等级：B
- 来源：Charles Schwab，《Stock Analysis Using the P/E Ratio》，https://www.schwab.com/learn/story/stock-analysis-using-pe-ratio
- 备注：市盈率受盈利波动、行业周期和会计处理影响很大，不同行业之间直接比较也不公平；该指南也强调市盈率要结合盈利增速、现金流等因素一起看，本条不主张用任何单一指标替代它。改掉做法是：把市盈率和盈利增速、现金流、负债、同行水平放在一起看，至少确认盈利是不是稳定、可重复的。

### 3. 买自己不懂业务的公司
<!-- 成本标签: 钱=多 时间=中 毅力=是 收益=大 口径=代价 -->
- 成本：不懂公司靠什么赚钱，就看不懂它为什么涨跌，遇到波动容易慌着卖出或盲目加仓，时间和本金都可能受损。
- 说人话：说不清它怎么赚钱，就先别急着买它。
- 收益：只买能讲清楚的公司，拿得更稳，遇到坏消息也知道该查什么。
- 证据等级：C
- 来源：无直接对照研究，属投资者教育共识
- 备注：本条是投资者教育中常见的能力圈提醒，没有直接对照研究可以量化“不懂业务必然亏损”；“懂”的程度也因人而异，不要求成为行业专家。改掉做法是：买之前用一两句话写清楚公司主营业务、主要客户和主要风险，写不出来就先学习或先放下。

### 4. 把一家公司的好产品等同于好股票
<!-- 成本标签: 钱=多 时间=少 毅力=否 收益=中 口径=代价 -->
- 成本：产品受欢迎不等于公司赚钱多，更不等于股价便宜，凭喜欢买入后可能发现利润很薄或估值已经很高。
- 说人话：喜欢它的产品，和它是一只好股票，是两回事。
- 收益：少为个人喜好买单，买入理由更接近公司的赚钱能力和价格。
- 证据等级：C
- 来源：无直接对照研究，属投资者教育共识
- 备注：本条是行为层面的提醒，没有直接对照研究可以量化“好产品等于好股票”的错误程度；好产品仍是加分项，只是不能单独作为买入理由。改掉做法是：喜欢产品之后再查三件事——公司是否持续盈利、利润率和现金流如何、当前价格相对盈利是否合理，三件都过关再考虑。

### 5. 财报只看利润，不看现金流、负债和分红可持续性
<!-- 成本标签: 钱=多 时间=中 毅力=些 收益=大 口径=代价 -->
- 成本：只看利润可能忽略纸面盈利没有变成真金白银、负债过重或分红靠借钱维持的情况，等问题暴露时损失可能已经不小。
- 说人话：账上赚了钱，不等于手里真的收到了钱，也不等于分红发得下去。
- 收益：更早发现财报里的风险信号，避免只被利润数字打动。
- 证据等级：B
- 来源：美国证券交易委员会（SEC），《Beginner's Guide to Financial Statements》，https://www.sec.gov/investor/pubs/begfinstmtguide.htm
- 备注：该指南介绍资产负债表、利润表、现金流量表和股东权益变动表四张报表的关系：利润是会计结果，现金流才是实际收到的钱。现金流、负债和分红只是财报分析的起点，不能凭一两项指标断定公司好坏，不同行业的负债和分红习惯也不同。改掉做法是：看利润时同步看经营现金流是否跟得上利润、负债水平是否在合理范围、分红有没有稳定的现金流支撑，三项中出现明显异常就先停下来细查。
