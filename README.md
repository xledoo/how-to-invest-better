# 高性价比投资指南 · 在线阅读页

一个单文件 HTML 阅读页，把《高性价比投资指南》的全部 8 章、40 条“投资中容易犯的错误”渲染成可搜索的页面。手机上打开就能看，不用装任何东西。

**在线阅读：** https://xledoo.github.io/how-to-invest-better/

> 仅供投资者教育，不构成投资建议。本书不推荐任何具体股票、基金或产品，也不承诺任何收益。

## 这是什么

本书总结新手投资者最容易犯的错误：每条写清犯这个错误会花掉什么、改掉能换回什么、证据多硬。40 条均为本仓库原创整理，按“容易犯的错误”的反面写法重写，不是照搬任何现有投资指南。

内容与证据标准对标 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（《高性价比人生指南》原书，34 章、772 条）：条目格式（成本 / 说人话 / 收益 / 证据等级 / 来源 / 备注）与成本标签沿用该书的写法，证据分级与引用规则也按该书的标准执行。单文件渲染方式参考 [cdyforever/how-to-live-better](https://github.com/cdyforever/how-to-live-better)（该仓库是原书的衍生渲染站，只做单文件阅读页，不维护原书内容）。凡借鉴原书某条思路或来源的条目，已在该条备注中注明出处链接。

每条包含：

- **成本**：这个错误会花掉什么（钱 / 时间 / 精力）
- **说人话**：一句话通俗结论，只写收益栏里已有的数据和结论，不加新的数字和断言
- **收益**：改掉这个错误能换回什么
- **证据等级**：A（有可量化的原始证据，如长期跟踪统计、期刊论文或官方原始文件，能给具体数字）/ B（有研究支撑但难以量化）/ C（行为与常识判断，无直接对照研究，备注中会明说）
- **来源**：所引用的报告、研究或投资者教育材料；没有直接来源的条目会如实说明
- **备注**：证据局限、适用范围，以及“改掉做法是……”

## 内容标准

- **只引原始文献**：期刊论文附 DOI、官方文件用原文链接；不引知乎、公众号、搜狐等二手转述；不编 DOI、标题和数字，找不到原文就不升级、不硬写。
- **数字可核对**：收益栏里的每个数字都能在来源原文中找到；不确定的数字宁可不写。
- **说人话不加新断言**：一句话一件事，通俗易懂；收益栏没写的症状、事实和机制解读，不许在说人话里新加。
- **交叉引用带锚点**：引用别的条目时写清“第 X 章第 Y 条（关键词）”，不写裸条号；插入或删除条目后要检查引用有没有被撞歪。
- **改完同步统计**：条目数、A/B/C 分级、外链数变了，要同步改 README、页脚统计和重新生成 `index.html`，三处数字保持一致。

## 页面特性

- **零外部资源**：没有 CDN、没有字体外链、不 fetch 任何数据，断网也能读
- 逐条卡片：错误标题、证据等级（A/B/C）、性价比档、成本标签
- **「说人话」高亮块**——每条最关键的一句话，页面上做得最显眼
- 全站关键词搜索（结果高亮）、只看 A 级、只看说人话
- 左侧目录带性价比色点，滚动联动
- 手机端：搜索框独占一行、顶栏向下滚动后自动收成一行、回到顶部按钮
- A / B / C 三主题切换
- 支持直接打印

## 本地使用

不用构建，双击 `index.html` 即可。

## 重新生成

```bash
# 全部 8 章
python build.py all -o index.html

# 只做某几章
python build.py 1 2 --repo .
```

源文件在 `book/` 目录下，每章一个 Markdown 文件（`book/01-*.md` … `book/08-*.md`），按原书 `eternity4719/HowToLiveBetter` 的条目格式编写。

## 自动发布

`.github/workflows/pages.yml` 在推送到 `master` 分支时重新生成 `index.html` 并部署到 GitHub Pages。也可以去 Actions 页面手动触发。
